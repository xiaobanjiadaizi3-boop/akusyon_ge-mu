# タイムアタック アクションゲーム

HTML5 Canvas で動作する、右へ進む横スクロール型アクションゲームです。

## 遊び方

`index.html` をブラウザで開くだけでプレイできます。

## 操作方法

| キー | 操作 |
|------|------|
| `A` | 左に移動 |
| `D` | 右に移動 |
| `W` | ジャンプ |
| `S` | しゃがむ (低い天井の下を通る) |
| `R` | リスタート |
| `Space` / クリック | ゲーム開始 / リトライ |

## 特徴

- **タイムアタック**: ゴールまでのタイムをミリ秒単位で計測
- **ベストタイム記録**: ブラウザに自動保存 (localStorage)
- **ステージギミック**: 足場、トゲ、低い天井 (しゃがみ必須)
- **デス数カウント**: チャレンジ回数を記録

ゴールの旗に触れるとクリアです。ベストタイム更新を目指しましょう！
